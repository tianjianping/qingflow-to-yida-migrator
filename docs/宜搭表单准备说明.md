# 宜搭表单准备说明

> 本说明针对迁移前的**表单准备工作**。宜搭不提供「通过 API 创建表单定义」的能力（钉钉 OA 审批模板接口与宜搭表单是两个独立产品体系），因此**目标表单必须在宜搭设计器中手动创建**，再在迁移控制台中完成关联。

## 1. 为什么必须手动创建

| 可能的途径 | 是否可用 | 原因 |
|---|---|---|
| 钉钉 OA 审批模板接口（`POST /v1.0/workflow/processCentres/schemas` 等） | ❌ 不可用 | 该接口创建的是**钉钉审批模板**，不是宜搭表单；两套产品体系数据不互通 |
| 宜搭 OpenAPI（`/v1.0/yida/forms` 等） | ❌ 不可用 | 宜搭开放 API 只能**读取表单定义、读写表单实例数据**，没有「创建/修改表单定义」的接口 |
| 宜搭设计器手动创建 | ✅ 推荐 | 官方唯一支持的表单构建方式，所见即所得 |

因此，迁移前需要在宜搭中：

1. 新建（或复用）一个**宜搭应用**（`appType`，形如 `APP_XXXXXXXX`），记录其 `systemToken`（应用设计器「开发设置」中获取）。
2. 在该应用下**手动创建表单**（记录 `formUuid`，形如 `FORM-XXXXXXXX`）。
3. 把该表单发布上线（草稿状态的表单无法通过 API 读写实例数据）。

## 2. 字段标题（label）必须与轻流字段名一致

自动映射（`scripts/02b_automap.py`）按 **「宜搭字段标题 label == 轻流字段名 queTitle」同名匹配** 建立字段对应关系，因此：

- 宜搭中每个需要迁移的字段，其**标题（label）必须与轻流对应字段的字段名（queTitle）完全一致**。
- 匹配是**全等比较**，以下差异都会导致匹配失败（自动映射跳过，需人工在 `mappings/<表单>_mapping.csv` 中手工补 `轻流queId`）：

| 差异类型 | 示例 |
|---|---|
| 多余/缺失空格 | 宜搭 `客户 名称` vs 轻流 `客户名称` |
| 全角 / 半角差异 | 宜搭 `客户（名称）` vs 轻流 `客户(名称)` |
| 标点 / 简繁体差异 | `帐号` vs `账号`、`联 系 人` vs `联系人` |
| 别名或重命名 | 宜搭 `客户名称` vs 轻流 `客户姓名` |

> 修改宜搭表单字段标题不会影响已录入的数据，可以放心调整后再发布。

## 3. 在控制台完成关联

启动 Web 控制台后（见 README「快速开始」）：

1. **配置凭证**：`设置 → 凭证` 页填写轻流、钉钉、宜搭、附件存储凭证（或使用环境变量），点击「测试连接」确认三个分区均连通。
2. **新建表单**：点击左侧「+ 新建表单」，在弹窗中：
   - **从轻流拉取应用**：下拉选择目标轻流应用，自动回填 `AppKey`；
   - **从宜搭拉取表单**：下拉选择已手动创建的宜搭表单，自动回填 `表单UUID`（表单名称留空时默认取宜搭表单标题）；
   - 也可以手动输入 `AppKey` / `表单UUID`。
3. 保存后系统自动生成表单配置，即可按「使用流程」开始迁移。

## 4. 核对清单（迁移前自检）

- [ ] 宜搭应用已创建，`appType` / `systemToken` 已配置
- [ ] 宜搭目标表单已创建并**发布**
- [ ] 需要迁移的字段在宜搭中的标题（label）与轻流字段名完全一致（含空格、全半角）
- [ ] 控制台「凭证」页三项测试连接均通过
- [ ] 表单关联正确（`AppKey`、`表单UUID` 已回填）
