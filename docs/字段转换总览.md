# 字段转换总览（轻流 → 宜搭）

> 本文档汇总本系统已支持的字段转换能力：转换管线、各类型实现方式与规则、跳过与兜底策略。
> 专项规则详见 [地址字段转换规则.md](地址字段转换规则.md) 与 [关联组件转换规则.md](关联组件转换规则.md)。

## 1. 转换管线

轻流原始数据 → `03_transform.py` 按映射表 `componentName` 列驱动格式转换（`extract_raw` 取内部值 + `wrap` 按宜搭格式包装）→ `04_batch_create.py` 写入宜搭。附件字段不走主管线，由 `03b_attachment.py` 独立阶段处理。

## 2. 普通格式转换（同型映射）

| 宜搭组件类型 | 实现分支 | 转换规则 | 宜搭输出格式 |
|---|---|---|---|
| TextField / TextareaField / RichText / RadioField / SelectField / DropdownField | `TEXT_TYPES` | 取 `values[0].value`（无则取 `dataValue`） | 字符串裸值 |
| NumberField / RateField | `NUM_TYPES` | `float()` 解析，失败写告警返回 None | 数字裸值 |
| DateField | `DateField` | 秒/毫秒自动判别（`>1e11` 视为毫秒）+ 6 种日期格式解析 | 毫秒时间戳 int |
| CascadeDateField | `CascadeDateField` | 每个值转毫秒时间戳 | 时间戳字符串数组 |
| CheckboxField / MultiSelectField / CascadeSelectField / CitySelectField | 列表分支 | 收集全部 value | 字符串数组 |
| EmployeeField | `EmployeeField` | 取 `optionId`/`userId`/`value`（即钉钉 userId） | userId 字符串数组 |
| DepartmentSelectField | `DepartmentSelectField` | 取 `deptId`/`departmentId`/`value` | deptId 字符串数组 |
| CountrySelectField | `CountrySelectField` | 取国家代码（如 CN/PG），`wrap` 时包装 `[{"value": raw}]` | 对象数组 |
| LinkField | `LinkField` | 取链接字符串，`wrap` 时包装 `[{"link","text"}]` | 对象数组 |

## 3. 结构化格式转换（专项规则）

> 映射层说明：02b 自动匹配默认按「宜搭字段标题 == 轻流字段名」同名匹配。当标题不一致时（如宜搭「省/自治区/直辖市」vs 轻流「省」），可在表单 config `labelAliases` 配置别名 `{"宜搭标题": "轻流标题"}`（内置兜底含 省/自治区/直辖市→省、市/自治州→市），02b 即可自动关联，避免手工补 mapping。

| 类型 | 实现函数 | 转换规则 |
|---|---|---|
| AddressField（轻流 queType=21 地址） | `to_yida_address()` | 逐级处理 `values[]`：`otherInfo` 为 6 位行政区划代码 → 追加进 `regionIds` + `regionText`（`zh_CN`=中文名、`en_US`=pypinyin 无调拼音，可选依赖缺失时回退原文）；无 `otherInfo` 的末级文本拼进 `address`；整字段无代码则纯文本兜底并告警。详见 [地址字段转换规则.md](地址字段转换规则.md) |
| AssociationFormField（轻流 queType=25 等关联） | `to_yida_association()` | **跨系统键解析**：轻流关联值=`values[0].value`（实为被关联记录的数据ID）→ 查 `<目标表单>_yida_instances.json` 的 `didToInst`（02c 按数据ID对账生成）得宜搭 `instanceId`，输出 `[{"appType","formUuid","formType":"receipt","instanceId","title","subTitle":""}]`；需在表单 config `associations` 段配置 `targetForm`/`titleField`；未命中写告警、不写脏关联。详见 [关联组件转换规则.md](关联组件转换规则.md) |
| TableField（轻流 queType=18，hasTableValues） | `extract_table()` | **子表单行映射**：轻流 `tableValues` 为行数组（每行是子组件 dict 列表）→ 宜搭对象数组 `[{子组件componentId: 值}, ...]`。子字段按轻流子字段 queId（02b 从样本行提取）→ 映射表子组件行（`componentName`=子组件类型）逐项转换，子表单内关联组件复用 `to_yida_association()` 的 didToInst 解析。子组件行由 02b 自动生成并标注 `子表单子组件`；子字段轻流 queId 仅存在于 tableValues 行内，与顶层 answers 无冲突 |

## 4. 附件与图片（已支持，独立阶段）

| 类型 | 实现脚本 | 说明 |
|---|---|---|
| AttachmentField / ImageField | `03b_attachment.py` | **已完整支持**。轻流 24h 签名 URL → 下载 → 本地缓存 → 上传自有 VPS 静态托管 → 构造宜搭附件数组 `[{downloadUrl, name, previewUrl, url, ext}]` → `insertOrUpdate` 按轻流数据ID 定位只写附件字段。主管线（03_transform）跳过附件字段避免重复写入。架构与部署详见 [attachment-migration-plan.md](attachment-migration-plan.md) 与 [vps-deploy-guide.md](vps-deploy-guide.md) |

附件迁移实测覆盖常见场景：截图类（单图/多图）、合同/商机类文档附件（含多附件），映射表中 `AttachmentField` / `ImageField` 组件行即可自动识别，无需额外配置。

## 5. 流水号（不支持 API 传值）

| 类型 | 状态 | 说明 |
|---|---|---|
| SerialNumberField | **不支持 API 传入值** | `batchSave` 传入自定义值会被系统按 `SERIALNUMBER()` 规则（如 yyyyMMdd+4 位自动计数）覆盖。映射表标记 `skip`，主管线不处理 |

## 6. 系统字段（映射表 queId 特殊处理）

| 轻流 queId | 语义 | 处理方式 |
|---|---|---|
| 0 | 编号 | 定位键，按映射表普通转换 |
| -17 | 数据ID | **匹配键**，04 阶段 `insertOrUpdate` 用它构造 searchCondition 定位更新 |
| 1 / 2 | 申请人 / 申请时间 | 映射表未含时从 `systemFields` 配置回退转换（时间转毫秒、用户转 userId 数组） |

## 7. 跳过与兜底

| 类型 | 处理 |
|---|---|
| AttachmentField / ImageField | 主管线跳过（由 03b 独立阶段迁移，见第 4 节） |
| SerialNumberField（流水号） | 跳过（宜搭系统生成，API 传值无效，见第 5 节） |
| 未识别的组件类型 | 按文本兜底并告警 |

## 8. 关键设计说明

- `wrap()` 阶段只有 **CountrySelectField / LinkField / AssociationFormField 三类需要 `[{}]` 包装**，其余组件一律裸值，依据宜搭《创建或更新表单数据格式说明》。
- 已支持能力分两类：**格式转换**（地址、日期、数字、成员、附件等，源值映射为目标格式）与 **跨系统键解析**（仅关联表单：轻流数据ID → 宜搭实例ID，依赖 02c 的 didToInst 索引，须先迁移被关联表单）。
- 组件构成差异大的表单（如以文本+地址为主、或以数字+附件为主）均可在 02b 自动映射后经本管线完成迁移，映射表自动生成，无需按表单手工调整规则。
- 尚未支持：流水号 API 传值，以及关联组件的多选场景（当前只取首个值，见关联规则已知限制）。子表单已支持（见第 3 节 TableField 行）。
